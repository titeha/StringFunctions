# IntRangeParser — контракт

## Назначение

`IntRangeParser` разбирает строку с числами и диапазонами целых чисел и возвращает
отсортированный список уникальных значений.

Публичный API:

```csharp
public static class IntRangeParser
{
    public static Result<List<int>> Parse(string? rangeSource, int maxRangeValue);
}
```

Метод не использует исключения для ошибок пользовательского ввода.
Ошибки валидации возвращаются через `Result<List<int>>` с `IsFailure == true`
и текстом ошибки в `Error`.

---

## Поддерживаемый формат входной строки

Поддерживаются следующие формы токенов:

- `N` — одиночное число
- `N-M` — диапазон от `N` до `M`
- `-N` — открытый слева диапазон
- `N-` — открытый справа диапазон

### Разделители токенов

Токены могут быть разделены любым символом из набора:

```csharp
" ,.;_:#!|\\/'\""
```

То есть допустимы, например:

- `1,2,3`
- `1;2;3`
- `1 2 3`
- `1|2|3`

---

## Семантика диапазонов

### Обычное число: `N`

`N` добавляется в результат как одно значение.

Примеры:

- `5` -> `[5]`
- `0` -> `[0]`

### Обычный диапазон: `N-M`

Добавляются все значения от меньшей границы к большей включительно.

Примеры:

- `3-7` -> `[3,4,5,6,7]`
- `7-3` -> `[3,4,5,6,7]`

### Открытый слева диапазон: `-N`

Интерпретируется как диапазон **от 1 до N**.

Примеры:

- `-5` -> `[1,2,3,4,5]`
- `-1` -> `[1]`

`-0` считается ошибкой, потому что открытый слева диапазон всегда начинается с `1`.

### Открытый справа диапазон: `N-`

Интерпретируется как диапазон **от N до maxRangeValue**.

Примеры:

- `10-`, `maxRangeValue = 15` -> `[10,11,12,13,14,15]`
- `0-`, `maxRangeValue = 5` -> `[0,1,2,3,4,5]`

---

## Правила для нуля и отрицательных значений

### Ноль

Ноль допустим **только при явном указании**:

- `0`
- `0-5`
- `0-`

Примеры:

- `0` -> `[0]`
- `0-3` -> `[0,1,2,3]`
- `0-`, `maxRangeValue = 3` -> `[0,1,2,3]`

### Отрицательные значения

Явно отрицательные значения и границы не поддерживаются.

Любая попытка задать значение меньше `0` считается ошибкой.

Примеры некорректного ввода:

- `1--5`
- `--5`
- `-1-5`

Важно: запись `-N` в начале строки — это **не отрицательное число**, а специальная форма
открытого слева диапазона.

---

## Ограничения по границам

### maxRangeValue

`maxRangeValue` должен быть не меньше `0`.

Иначе метод возвращает `Failure`.

### Допустимые явные значения и границы

Все **явно указанные** числа и границы диапазонов должны лежать в пределах:

```text
0..maxRangeValue
```

Исключение: форма `-N`, у которой левая граница неявная и всегда равна `1`.

Примеры:

- `5`, `maxRangeValue = 10` -> ok
- `0-10`, `maxRangeValue = 10` -> ok
- `11`, `maxRangeValue = 10` -> error
- `5-12`, `maxRangeValue = 10` -> error
- `-12`, `maxRangeValue = 10` -> error

---

## Позиционные правила

### `-N`

Открытый слева диапазон допустим только **первым токеном**.

Пример:

- `-5,10` -> ok
- `10,-5` -> error

### `N-`

Открытый справа диапазон допустим только **последним токеном**.

Пример:

- `10-,15` -> error
- `5,10-` -> ok

---

## Пробелы вокруг `-`

Пробелы вокруг символа `-` внутри диапазона допустимы.

Поддерживаются, например:

- `10 - 20`
- `10- 20`
- `10 -20`
- `- 20`
- `10 -`

Перед разбором пробелы, непосредственно примыкающие к `-`, игнорируются.

Важно:

- пробелы **вокруг `-`** не считаются разделителями токенов
- пробелы **вне диапазонной конструкции** остаются обычными разделителями

Примеры:

- `10 - 20 30` -> токены `10-20` и `30`
- `1 2 3` -> три отдельных токена

---

## Дубликаты и порядок результата

Результат всегда:

- без дубликатов
- отсортирован по возрастанию

Примеры:

- `1,2,2,3` -> `[1,2,3]`
- `5-7,6,7,8` -> `[5,6,7,8]`

---

## Ошибки

Метод возвращает `Failure`, если:

- `rangeSource == null`
- `maxRangeValue < 0`
- встречен некорректный токен
- обнаружено больше одного символа `-` в токене
- токен не удаётся распарсить как число/диапазон
- токен нарушает позиционные правила (`-N` не первый, `N-` не последний)
- явная граница выходит за пределы `0..maxRangeValue`
- встречена попытка задать отрицательное значение
- встречен `-0`

---

## Примеры

### Пример 1

```csharp
Parse("1,2,5-7", 10)
```

Результат:

```csharp
[1,2,5,6,7]
```

### Пример 2

```csharp
Parse("-5,10-", 12)
```

Результат:

```csharp
[1,2,3,4,5,10,11,12]
```

### Пример 3

```csharp
Parse("0-3, 10 - 12", 20)
```

Результат:

```csharp
[0,1,2,3,10,11,12]
```

### Пример 4

```csharp
Parse("7-3", 10)
```

Результат:

```csharp
[3,4,5,6,7]
```

### Пример 5

```csharp
Parse("10,-5", 20)
```

Результат:

```csharp
Failure
```

Причина: `-N` допустим только первым токеном.

### Пример 6

```csharp
Parse("-0", 20)
```

Результат:

```csharp
Failure
```

Причина: открытый слева диапазон начинается с `1`, `-0` недопустим.

---

## Замечания по реализации

Внутри парсер оптимизирован под тип `int` и сценарии:

- маленькие и средние диапазоны
- большие плотные диапазоны
- большие, но разрежённые диапазоны

Для этого используются разные внутренние стратегии материализации результата, но это
не влияет на публичный контракт метода.
